# fotos-sala

Family digital photo frame. Family uploads photos from a phone PWA; an old iPad (iOS 9.3.6) shows them as a slideshow.

- **Upload app:** `index.html` (open with `#c=<family code>`)
- **iPad screen:** `pantalla.html` (open with `#c=<family code>`)
- **Live URL:** https://chokorad.github.io/fotos-sala/
- **Repo:** https://github.com/chokorad/fotos-sala
- **Backend:** Firebase Firestore (free plan), via REST
- **Deploy:** push to `main`; GitHub Pages serves the repo root

Setup steps (Spanish): `LEEME.md`. For agents: start with `AGENTS.md`.
